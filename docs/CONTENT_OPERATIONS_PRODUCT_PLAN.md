# 社媒工作台产品规划（已确认基线）

## 产品定位

这是一个本地优先、单用户运行的社媒工作台，不局限于股票回测视频。每位使用者在自己的电脑上完成内容策划、生产、资产管理、多平台发布和运营复盘，不建设团队、成员、角色或云端权限体系。

系统长期围绕三类对象组织：

1. **内容工作流**：定义不同赛道如何选题、生产和生成视频。
2. **内容资产**：集中保存成片、封面、标题、简介、话题和素材。
3. **发布账号**：保存各平台本地登录会话、发布规则和执行结果。

工作流负责生产内容，账号负责承接发布，两者保持解耦。发布时选择一个视频，再勾选一个或多个账号进入发布队列。

## 已确认的产品原则

- 工作流可以复制，在现有配置基础上创建新赛道。
- 生产流程调试稳定后可以自动选题并直接产出视频，生产阶段不要求逐条人工确认。
- 发布阶段必须保留人工确认入口。
- 发布前允许手动修改标题、封面、简介和话题。
- 一个视频可以勾选多个账号发布；每个账号形成独立任务，分别记录状态和证据。
- 发布模式支持立即发布、定时发布、账号固定时段和批量队列。
- 批量队列支持固定间隔、随机延迟、暂停、继续、失败处理和人工接管。
- 首页以系统运行数字、待办、生产趋势和发布排期为核心，不做营销型首页。
- 数据分析只展示本机真实生产、发布和账号数据；没有平台数据接口时不伪造播放量、点赞量或收益数据。
- 视觉采用现代化深色工作台风格，强调信息密度、清晰层级和低干扰操作。

## 信息架构

### 总览

- 系统运行状态
- 今日完成、生产中、待发布、异常、成功率
- 内容产出趋势
- 工作流效率
- 需要处理
- 接下来发布

### 内容生产

- 工作流：模板、复制、导入导出、配置和启停
- 生产控制台：自动选题、题材库存、生产策略
- 运行中心：队列、进度、错误和重试
- 手动创建：单次生产和调试

### 内容资产

- 内容库：网格/列表、筛选、搜索、收藏、归档
- 内容详情：视频、标题、简介、话题、横竖封面和发布入口
- 素材库：封面、BGM、源文件和素材状态

### 内容发布

- 发布台：选择内容、账号和发布模式，执行最终确认
- 发布日历：查看排期并维护账号固定时段
- 发布记录：结果、链接、失败原因、证据和重试

### 账号管理

- 抖音、小红书、微信视频号本地会话
- 扫码绑定、检测、解绑、删除
- 每账号发布时段、最小间隔、随机延迟、每日上限
- 后续所有发布和平台数据均按账号关联

### 数据分析

- 生产成功率、平均耗时、市场/题材分布
- 发布成功率、失败原因、账号任务分布
- 后续通过官方接口或导入数据扩展平台表现，不使用估算值

### 系统管理

- 数据源和生产设置
- 运行日志与脱敏诊断
- 数据库/关键配置备份
- 本机版本和在线更新状态

## 生命周期

`工作流配置 → 自动选题与生产 → 内容库 → 人工发布确认 → 多账号队列 → 发布结果与证据 → 数据分析`

生成失败回到运行中心处理；发布失败进入发布记录和需要处理；登录或短信验证会暂停相关账号队列，等待人工接管。

## 当前版本已经落地

- 第三版双导航视觉系统和数字型总览。
- 可复制、导入导出、配置并运行的工作流中心。
- 内容库双视图、元数据编辑、收藏与归档。
- 发布台、发布日历、发布记录和账号固定时段。
- 批量发布的固定间隔与随机延迟。
- 账号管理、真实数据分析、日志、备份和更新状态入口。
- 全局搜索、响应式布局和移动端底部导航。

## 后续扩展边界

- 新视频赛道以新增工作流类型和生产适配器实现，不复制整套站点。
- 新社交平台以账号适配器和发布适配器接入，不侵入内容生产。
- 平台互动数据必须有明确数据来源和授权后再接入分析模块。
- 单机优先不排斥将来增加远程任务节点，但不会提前引入团队权限复杂度。
