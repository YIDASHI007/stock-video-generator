# 内容自动化工作台 v0.1.11

## 快速增量更新

- 发布流程会自动下载上一稳定版本作为差分基线，并生成 Velopack delta 增量包。
- 稳定版若未生成增量包会直接阻止发布，避免再次静默退化成 250 MB 以上的全量更新。
- 客户端优先使用增量更新；仅在首次安装、跨度过大或差分校验失败时回退完整包。
- 更新提示新增“增量更新/完整更新”和预计下载体积，下载界面继续展示速度、进度与剩余时间。
- 下载期间保持工作台服务运行，下载及校验完成后才关闭服务、替换程序并自动重启。

## 工程规范

- 新增桌面更新规范，明确发布资产、增量兜底、用户体验和 CI 校验要求。
- GitHub Release 必须同时包含完整包、增量包、安装包、便携包及更新索引。
