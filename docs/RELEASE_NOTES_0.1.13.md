# 社媒工作台 v0.1.13

## 源码运行与增量更新

- 默认支持 Python + Vite 源码运行，不再要求每个功能版本构建 EXE 和安装包。
- 桌面启动时检查 GitHub 上游分支；发现新版本后显示当前版本、目标版本和提交摘要，并由用户确认是否更新。
- 更新使用 Git 快进拉取，仅传输变化文件；只有 Python 或 Node.js 依赖定义变化时才同步依赖。
- 本地存在未提交修改或分支已经分叉时自动停止更新，避免覆盖用户代码。
- “备份与更新”页面新增源码版版本状态、远程版本和联网检查入口。
- 原有用户数据目录继续保存数据库、视频、账号会话和分析结果，不随源码更新覆盖。

## AI 文案分析

- 系统管理重新拆分为“数据源、AI 模型、系统配置、优化策略、运行日志、备份与更新”，不再把不同设置挤在同一长页面。
- AI 模型页新增 DeepSeek 模型、API Key、本机加密保存和连接测试。
- 对标账号的方法论分析改用大模型提炼可执行的写作方法，并可生成本地 Skill。
- 当前支持 DeepSeek V4 Flash 与 DeepSeek V4 Pro。

## 对标账号任务体验

- 批量提取后显示总进度、完成数、处理中、排队中和失败数。
- 作品文案与视频继续缓存到工作台本地，可离线查看已归档内容。
