# 内容自动化工作台 v0.1.10

## 对标账号与作品档案

- 新增抖音对标账号管理，支持通过主页分享链接同步账号作品、标题与基础互动数据。
- 支持将账号池中的抖音登录凭证安全同步给提取服务，减少登录失效导致的解析失败。
- 新增账号定位、内容支柱、表达风格和文案节奏画像，提取结果与账号、作品持续绑定。
- 新增独立作品文案档案页，提供视频播放、完整口播文案、精准时间轴、版本记录和文件下载。
- 账号及作品档案保存到工作台本地，Docker 提取服务离线时仍可浏览已有数据。

## 重新提取体验

- “重新提取”接入真实后台任务，不再只是前端状态效果。
- 实时展示解析链接、下载视频、语音识别和结果整理等阶段、百分比与已用时间。
- 页面刷新后可恢复任务跟踪；完成后自动刷新档案，失败时展示实际错误原因。
- 修复历史口播文案编码异常，并增强本地归档兼容处理。
