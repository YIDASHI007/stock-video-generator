# 股票视频工作台 v0.1.7

## 启动中心

- 启动窗口升级为紧凑型生产控制面板，明确显示版本号和开发版/桌面版运行模式。
- 用“服务、端口、数据、媒体、更新”五段状态轨道展示启动检查进度。
- 启动失败时提供重新检查和日志入口，不再用整窗点击关闭代替故障处理。
- 手动打开启动中心时停留在结果页，避免检查完成后再次自动跳转浏览器。

## 系统托盘

- 增加当前版本、运行模式和后台服务状态。
- 增加显示启动中心、重启后台服务、打开输出/数据/日志目录和查看发布说明。
- 更新检查会区分开发版、桌面安装版、便携版和未配置更新源。

## 稳定性

- 修复开发环境中启动器与后台 Python 可执行路径不一致时，退出后可能遗留端口监听的问题。
