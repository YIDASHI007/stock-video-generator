# 内容自动化工作台 v0.1.8

## 远程抖音链接提取

- 内容资产新增“链接提取”，可粘贴抖音分享文本并查看解析、下载、转写与整理进度。
- 支持下载原视频、发布文案、口播文案、SRT 字幕和时间轴 JSON。
- 支持把远程结果导入本机独立内容目录，保留来源、作者、语言、时间轴和权利确认信息。
- 导入后的外部素材会显示在内容库，可直接播放、下载、查看来源和识别文案。

## 安全连接

- 工作台仅通过本机后端访问远程提取服务，API Key 不会发送到浏览器。
- Windows 安装版使用当前用户 DPAPI 加密保存访问密钥。
- 远程服务只接受 API v1 客户端密钥，支持客户端停用、任务限流、文件隔离和审计日志。
- Cloudflare Tunnel 通过 Docker 可选配置提供异地公网连接，原始服务端口继续只监听本机。

## 可靠性

- 本地与远程任务建立持久映射，关闭工作台后仍可继续查询。
- 提取服务重启后会恢复历史任务，并将被中断任务明确标记。
- 增加真实链接端到端验证：工作台提交、Docker 下载与转写、结果下载和本地导入。
