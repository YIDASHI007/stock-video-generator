# Account Management Override

- Use a dense horizontal account list: one account per row, never a two-column card gallery.
- Columns: identity, connection state, publishing rule, recent activity, row actions.
- Keep bulk selection in the first column and show a contextual bulk-action strip.
- The binding dialog is a two-step flow: account/rule configuration, then inline QR login.
- Required configuration: platform, local display name, automatic-publish permission, preferred time, daily limit, minimum interval, randomized delay.
- Hide the generated local account identifier behind an advanced disclosure.
- Use semantic state colors. Platform color may identify the platform mark only; it must not color the whole row.
- Desktop rows remain horizontal. On narrow screens, each row becomes a compact two-column record without horizontal page overflow.
